# prereject

**보내기 전에, AI 심사위원 팀이 당신을 먼저 떨어뜨려 봅니다.**

지원서·사업계획서·자기소개서·피치덱을 붙여넣으면, "통과할까?"가 아니라
**"왜 반려될까?"**를 찾아 반려 이유 + 그대로 붙여넣을 수정 문구를 돌려줍니다.

> 핵심 사상: 내부 점수는 **개선 엔진**이지 당락 예측기가 아니다.
> 점수가 몇 점인지가 아니라, 그 점수가 **어디를 고쳐야 하는지 가리키는가**가 전부다.

## 무엇을 하나

- **이중 채점** — 절대점수 + 경쟁 컷("평범하면 컷").
- **탈락사유 헌터 (E1~E8)** — 배점표 밖에서 실제로 떨어뜨리는 요인(자격·형식·자기파괴적 서술·미구현 과장·근거 없는 수치·평범함). 기본 판정은 CUT.
- **그대로 붙여넣을 수정 문구** — 약점을 "검증 계획"으로 프레이밍(정직 ≠ 자기비하).

## 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                  # http://localhost:3000
```

## 스택

Next.js (App Router) · Anthropic Claude · TypeScript. 배포는 Vercel.
